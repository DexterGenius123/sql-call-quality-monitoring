# Мониторинг качества звонков

Портфолио-проект на PostgreSQL для контроля качества работы контакт-центра. Он моделирует процесс верификации звонков: данные о разговорах, результаты проверок, нарушения сценария и отчёты для руководителя.

## Бизнес-задача

Операционный менеджер хочет ежедневно видеть, какие звонки требуют повторной проверки, какие менеджеры чаще нарушают сценарий и достигается ли целевой SLA по контролю качества.

## Что демонстрирует

`SELECT`, `WHERE`, `ORDER BY`, `JOIN`, `CASE`, CTE, агрегаты, оконные функции, проверку качества данных и представления. Все данные синтетические и не содержат персональных данных.

## Структура

| Файл | Назначение |
| --- | --- |
| `sql/01_schema.sql` | таблицы, ограничения и индексы |
| `sql/02_seed.sql` | демонстрационные данные |
| `sql/03_reports.sql` | 14 рабочих аналитических запросов |

## Быстрый старт

```bash
createdb call_quality
psql -d call_quality -f sql/01_schema.sql
psql -d call_quality -f sql/02_seed.sql
psql -d call_quality -f sql/03_reports.sql
```

Запросы можно выполнять по одному в DBeaver, pgAdmin или DataGrip. Скрипт `03_reports.sql` содержит комментарии с назначением каждого отчёта.

## Ключевые выводы, которые можно получить

- найти звонки без проверки и звонки с просроченным SLA;
- отследить критические нарушения скрипта;
- сравнить менеджеров по среднему баллу и доле успешных звонков;
- проверить полноту и согласованность данных;
- составить очередь на повторную проверку.
